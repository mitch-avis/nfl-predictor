# Betting report labels: the whole edge or the model's part beyond the spread

Generated by `.agents/sos_port/betting_labels.py`; do not edit by hand. The protocol is
`protocols/betting_labels.md`, committed before any game was scored. Per game and seed, on the home
side, `edge = p_model - p_ml` claims `p_model` and `beyond = p_model - p_spread` claims `q_beyond =
p_ml + beyond`. The instrument is `d = (q_beyond - y)^2 - (p_model - y)^2`, `q_beyond` unclipped,
averaged over the two seeds per game, then its mean over the governing games with a bootstrap over
games (5,000 resamples, numpy seed 0, 95% percentile interval). A negative `d` means the beyond
claim scored better.

Reproduce from the repository root (it reads the inputs below and writes only this file and
`betting_labels.json`):

