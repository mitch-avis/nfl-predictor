## Findings

**P3: an infinite sigma passes the "positive sigma" check.**

- Where: `src/nfl_predictor/reporting/betting_report.py:143`, and
  `src/nfl_predictor/weekly_run/pipeline.py:550`.
- What happens: `not floor_sigma > 0` rejects zero, negative values and NaN, but accepts `+inf`.
  The report is then built with `market_home_prob_spread == 0.5` for every game, so the split
  columns are nonsense:
  - game g1 has spread `-2.5`, yet its spread probability is `0.5`;
  - its beyond-spread edge is `0.0879` and its gap is `-0.0339`.
- What doesn't change: the labels, which use the whole edge.
- Likelihood: the pipeline helper passes an all-`inf` `floor_sigma` column straight through, but
  production sigma comes from a finite error pool, so this is very unlikely in practice.
- Suggested fix (test first): use `math.isfinite(floor_sigma) and floor_sigma > 0` in both places.
  This slightly widens the approved "non-positive sigma check", so I've listed it as a question
  below.

**P3: the Review line in the decision log doesn't name the reviewer.**

- Where: `.agents/sos_port/decisions/betting_edges.md:139-142`.
- What: it says "a reviewer subagent" with no agent ID (`agent-a8512322c21aed91f`), and it doesn't
  record this re-check of the fix commits.
- Suggested fix: the coordinator adds both at merge.

    # Arrange
    predictions = pd.DataFrame({"floor_sigma": [math.inf, math.inf]})

    # Act

**Passed:**

- Zero, `-0.0`, `-1` and `-inf` raise, both with and without spreads. NaN raises, both with and
  without spreads.
- `_report_floor_sigma` returns None for all-zero, all-negative, all-NaN and two different values,
  and returns `13.5` for `[13.5, NaN]`.
- **A week with no moneylines** (all NaN):
  - the spread probability and the beyond-spread edge are still computed correctly;
  - the gap and the edge are NaN;
  - every column outside the split equals the report built without sigma.
- **A pick'em spread** (`0.0` and `-0.0`): the spread probability is exactly `0.5`, the
  beyond-spread edge is exactly `model_home_prob - 0.5`, and `edge = beyond + gap` holds to
  `1e-15`.
- A tiny positive sigma (`1e-300`) saturates to `[1.0, 0.0]` without error.
- **The rule's boundaries:**
  - a top-decile share of exactly `0.5` keeps the labels ("more than half" is strict);
  - a tie where `|gap| == |beyond|` doesn't count as gap-led;
  - with no real-moneyline seasons, only the all-games group remains.
